## ⌨️ Keyboard Shortcuts

Seamlessly control audio and celebrations with keyboard shortcuts:

| Key | Action |
| :---: | :--- |
| <kbd>Space</kbd> | Play / Pause *Vande Mataram* background instrumental |
| <kbd>M</kbd> | Toggle Audio Mute / Unmute |
| <kbd>↑</kbd> | Increase Volume by 5% |
| <kbd>↓</kbd> | Decrease Volume by 5% |

*(Shortcuts are disabled when editing text in inputs or textareas.)*

## 🚀 Quick Start

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18.0.0 or later recommended)
- `npm`, `pnpm`, or `bun`

### Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Rahul08319/pixel-perfect.git
   cd pixel-perfect
   ```

2. **Install project dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:5173`.

4. **Run production build:**
   ```bash
   npm run build
   ```

5. **Execute test suite:**
   ```bash
   npm run test
   ```

## 🏗️ Architecture & Tech Stack

```text
pixel-perfect/
├── public/
│   ├── banner.svg            # Regal SVG header banner for GitHub & showcase
│   └── favicon.png           # Tricolor celebration icon
├── src/
│   ├── assets/
│   │   └── vandemataram.mp3  # Authentic instrumental score
│   ├── components/
│   │   ├── AshokaChakra.tsx  # Geometric 24-spoke SVG chakra with rotation
│   │   ├── MusicPlayer.tsx   # Glassmorphic pill with audio visualizer
│   │   ├── QRCodeModal.tsx   # Mobile camera QR scan & sharing modal
│   │   ├── patrioticQuotes.ts# Curated quotes dataset from national heroes
│   │   └── ui/               # Radix UI primitives & sonner toast
│   ├── pages/
│   │   ├── Index.tsx         # Central celebration studio & card canvas
│   │   └── NotFound.tsx      # 404 error page
│   ├── index.css             # Aurora gradients, gold foil keyframes, glassmorphism
│   ├── App.tsx               # Route provider & toast notifications
│   └── main.tsx              # Application entrypoint
├── index.html                # Google Fonts (Plus Jakarta Sans, Cinzel, Playfair)
├── tailwind.config.ts        # Custom patriotic tokens & animations
└── package.json
```

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Build Tool**: [Vite 5](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 3.4](https://tailwindcss.com/) + CSS Glassmorphism
- **Typography**: Plus Jakarta Sans, Cinzel Decorative, Playfair Display, Rozha One
- **Icons**: [Lucide React](https://lucide.dev/)
- **Exporting**: `html2canvas` (retina 2X image) + `jspdf`
- **Effects**: `canvas-confetti`
- **Testing**: [Vitest](https://vitest.dev/)
